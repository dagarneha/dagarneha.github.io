# Neha Dagar — Graphic Designer Portfolio

Dark editorial single-page portfolio for **Neha Dagar**, Graphic Designer at ProofHub.

## Direction

Type-led, sparse, work-first layout inspired by editorial creative portfolios:

- Giant brand name as the first-viewport signal
- Manifesto + selected work + about + open contact
- Near-black ground, cream type, coral accent
- **Display:** Bebas Neue · **Body:** Outfit · **Labels:** Space Mono

## Sections

1. Intro (hero)
2. Manifesto
3. Selected work (ProofHub, Venus Remedies, Ultra Healthcare)
4. About + experience
5. Contact
